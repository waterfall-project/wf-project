# Installation

## What the screen shows

The installation of the platform, outside any project, in an **Installation** card:

- **Company name**, which the exported files bear: a quote exported after a change bears the new name;
- **Currency**, the single currency of the installation, in which all the amounts are expressed;
- **Default language**, that of the interface until an account chooses one;
- **Time zone**, the one the current day is understood in.

The currency, the default language and the time zone are fixed at installation: no screen modifies them.

## Its commands

- **Modify the company name** opens its form: the name is required, of 200 characters at most. The command is offered only to whoever may modify the installation; with the permission to view it alone, the card is read without a command.

The screen is offered only to whoever may view the installation. The service keeps what is written: a refusal leaves the name as it was.

## Its columns and computed values

Nothing is computed here: every value is the one the server holds.

## Keyboard gestures

- `Tab` goes through the screen; `Enter` presses the command.
- `F1` opens this help.
